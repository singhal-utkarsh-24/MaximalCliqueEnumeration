Graph algorithms · C++ · OpenMP

Maximal Clique Enumeration

Three ways to list every maximal clique in a graph, implemented in C++ and run on real networks from SNAP, up to 1.7M nodes and 11M edges. Below is a live playground running the same algorithms in your browser.

Try the playground See benchmarks Source on GitHub

ELS

Eppstein, Löffler & Strash, 2010

Bron–Kerbosch with pivoting, started from each vertex in a degeneracy order so every subproblem stays small. Also ships as an OpenMP build.

src/els.cpp

Tomita

Tomita, Tanaka & Takahashi, 2006

Bron–Kerbosch that picks the pivot with the most neighbours among the candidates, which gives the worst-case optimal O(3n/3) bound.

src/tomita.cpp

Chiba

after Chiba & Nishizeki, 1985

Walks vertices in degree order and extends cliques one vertex at a time, checking maximality at the leaves. No pivot pruning, which is why it is the slowest here.

src/chiba.cpp

Run it yourself

git clone https://github.com/rushipatel296/MaximalCliqueEnumeration
cd MaximalCliqueEnumeration
make
./bin/els data/sample.txt
OMP_NUM_THREADS=8 ./bin/els_parallel data/sample.txt

Input is a plain edge list: the first line is n m, then m lines of u v with 0-based vertex ids. The SNAP graphs (wiki-Vote, email-Enron, as-Skitter) need a quick cleanup first: drop duplicate edges and renumber vertices to 0…n−1.
